# pstack for Codex

Generated from Lauren Tan's pstack. This package includes native Codex instructions, all skills and playbooks, their supporting files, and the MIT license.

## Install

See the [distribution repository](https://github.com/janozeli/pstack-codex) for marketplace installation.

## Start

Run `$pstack:setup-pstack`, then `$pstack:poteto-mode` with a concrete goal and verification condition. Use `$pstack:poteto-help` for guidance.

Read the [guide](docs/guide/README.md) and [runtime contracts](docs/runtime.md). The package executes without the source checkout or another plugin distribution. Optional host capabilities remain explicit requirements of the workflows that need them.
